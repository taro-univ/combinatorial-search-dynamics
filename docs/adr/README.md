# Architecture Decision Records

重要な技術判断を、決定時の背景と影響とともに残す。新しいADRは連番を付け、次の雛形を使う。受理済みADRの内容を変更する判断は、新しいADRを追加して参照関係を記録する。Phase 3の参照solver判断は[ADR-008](ADR-008-ortools-solver-abstraction.md)に記録し、ADR-007は仕様書に従い将来のOptuna判断用に予約する。

```markdown
# ADR-NNN タイトル

## Status
Proposed / Accepted / Superseded

## Context
決める必要がある事項と制約。

## Decision
採用する判断。

## Alternatives
検討した代替案。

## Consequences
利点、制約、将来の変更条件。
```
